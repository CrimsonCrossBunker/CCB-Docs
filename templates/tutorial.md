# Tutorial template / 教程模板

Use for a learning journey that produces a working result. Metadata belongs in
`docs-catalog.yml`; generated front matter must not be copied here.

## Outcome / 完成结果

State what the reader will build and how they can verify it.

## Prerequisites / 前置条件

List knowledge, tools, source commit, and linked prerequisite document IDs.

## Steps / 步骤

Use numbered, tested steps. Mark executable blocks with their validation ID.

## Verify / 验证

Give exact expected output and recovery guidance for common failures.

## Next / 下一步

Link the paired-language how-to and reference pages.
